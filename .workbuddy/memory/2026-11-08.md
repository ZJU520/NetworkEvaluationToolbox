## v1.5：新增带宽测速维度（NetToolbox）
- 用户诉求：加入网络测速判断实际带宽。
- 新增 Testers/SpeedTester.cs：多线程（默认 6 并发）下载/上传测速，串行安排在压测之后（避免测速抢带宽污染延迟/丢包数据）。
- 下载端点：`https://speed.cloudflare.com/__down?bytes=25000000`（100MB 版本会被 Cloudflare 限流返回 0 字节，25MB 正常）；上传端点 `https://speed.cloudflare.com/__up`。
- 评分：下载 60% + 上传 40%；带宽档位 dl 500/200/100/50/20/10/1 Mbps → 100/95/88/75/55/40/25/10；ul 100/50/30/10/5/1 → 100/92/82/65/50/35/10。
- 权重：另立维度（不改动其它维度权重），总分按启用维度归一化。
- 报告：新增"带宽测速"维度行（下载/上传 Mbps、传输量、耗时、并发数）+ 低带宽建议。
- 验证：源码编译 0 警告 0 错误；源码版与发布版均实测出数（沙箱环境 ↓6.5~7.9 / ↑4.6~6.4 Mbps，沙箱出口带宽限制所致，非程序问题），六维度全有数据。
- 分发包：`NetToolbox_v1.5_绿色版.zip`（66.8MB / 解压 464 文件），已删除 v1.0~v1.4 旧包。
- 坑：PowerShell `Get-ChildItem 通配符 | Remove-Item` 在含中文文件名时绑定失败，改用 `Remove-Item -LiteralPath` 显式路径；`Add-Type` 与"Bash 里调 powershell"被安全策略拦截，校验 zip 用 bash 的 `unzip -l`。
